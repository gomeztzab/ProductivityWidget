## 3. Funciones que modifican el sistema

Focus Pro incluye funciones que alteran el comportamiento del sistema operativo. Al usar estas funciones, reconoces y aceptas lo siguiente:

### Website Blocker
- Modifica el archivo `C:\Windows\System32\drivers\etc\hosts` de Windows para bloquear el acceso a sitios web.
- Requiere permisos de administrador.
- Los cambios se revierten automaticamente al terminar la sesion o al cerrar la app.
- Si la app se cierra de forma inesperada, los cambios podrian persistir hasta que se restauren manualmente o se reabra la app.

### Interaction Lock
- Crea ventanas de pantalla completa "siempre encima" en todos los monitores.
- Bloquea la interaccion con otras aplicaciones mientras esta activo.
- Se desactiva al terminar el bloque actual de Pomodoro.

### Screen Lock
- Muestra una pantalla de bloqueo que cubre el escritorio.
- Impide el acceso visual a otras aplicaciones durante la sesion.

### Exit Lock
- Impide cerrar la app mientras el temporizador esta activo.
